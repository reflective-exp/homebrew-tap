# Reflective Software Experiments Homebrew Recipes

Extra bits and pieces for installing things on MacOS.


## Installation

```shell
brew tap reflective-exp/tap
```


## Usage

```shell
brew install reflective-exp/tap/<recipe>
```

Available recipes:

- [reflective-exp/tap/compostbin](https://github.com/reflective-exp/compostbin) - run Claude in an Apple container

## Brewfile

```shell
tap "reflective-exp/tap"
brew "reflective-exp/tap/<recipe>"
```
